# Spinoza-Ethics-RAG-APP

ChatGPT model gpt-4o-mini was used in this project to create an AI 

The purpose was to create an AI with a word for word exact knowledge of Spinoza Ethics. This was achieved by converting the translation of R. H. M. Elwes into vectorized form using OpenAI's own service.
The LLM was given the liberty to interpret ethical scenarios using the Spinoza Ethics as a basis for reason.

This is to demonstrate how LLM's can take a piece of philosophical text that can take an average person a week to read and let alone understand for an LLM mere seconds.
